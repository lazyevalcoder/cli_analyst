- ai data analyst
- cli based (for now)
- graph based
phase 1: structural knowledge graph (Understand what exists in the data)
phase 2: diagnostic (causal)  knowledge graph (Explain why something happened)


workflow:
- llm prompts for input file
- user uploads/directs csv file
- phase 1 gets activated
- llm collects metadata, relationships and creates structural.graph.json
- llm creates causal.graph.json for the metrices.
- typically causal edges are following but not limited to just these:
* supports
* explains
* causes
* correlates
* depends_on
* derived_from
* validated_by

tech:
- use OpenAI sdk for interaction with llm
- for llm, there will be a llama.cpp inference running, use that api.
- ensure when user runs the program, initially it checks if llm is available.
